# Pilot Experiment

This repository contains the implementation of a pilot experiment for my master's thesis on prompt injection attacks against AI agents.

The project uses **AgentDojo** to investigate how AI agents behave when completing legitimate tasks and how their behavior may be affected by prompt injection attacks, memory, and multi-step attack scenarios.

## Technologies

- **Python 3.12** — Programming language
- **uv** — Dependency and environment management
- **AgentDojo** — Agent environment and evaluation
- **pytest** — Testing
- **pandas and SciPy** — Data processing and analysis

## Setup

Clone the repository:

```bash
git clone https://github.com/Abdiqani0122/Pilot-Experiment.git
cd Pilot-Experiment
```

Install dependencies:

```bash
uv sync
```

## Current Progress

- **Phase 1:** Project initialization and dependency setup.
- **Phase 2:** Developing and verifying a baseline agent that completes a legitimate AgentDojo task.

Future work will focus on prompt injection attacks, agent memory, attack chains, and evaluation.
